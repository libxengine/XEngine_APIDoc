函数

DataBase_MySQL_ExecQuery

功能

执行查询语句

语法

bool DataBase_MySQL_ExecQuery(XNETHANDLE xhData, LPCXSTR lpszQueryStr, XCHAR*** ppptszResult, __int64u* pInt_Row, __int64u* pInt_Column)

参数

 参数.一：xhData
  In/Out：In
  类型：数据库句柄
  可空：N
  意思：要对哪个SQL客户端执行
 参数.二：lpszQueryStr
  In/Out：In
  类型：常量字符指针
  可空：N
  意思：SQL语句
 参数.三：ppptszResult
  In/Out：Out
  类型：三级指针
  可空：N
  意思：导出查询的数据库记录集
 参数.四：pInt_Row
  In/Out：Out
  类型：整数型指针
  可空：N
  意思：结果集的行数
 参数.五：pInt_Column
  In/Out：Out
  类型：整数型指针
  可空：N
  意思：结果集的列数

返回值

类型：逻辑型
意思：是否成功

备注

通过这个函数可以查询内容，导出的一个可以操作的记录集，不使用必须释放
      同sqlite,返回的第一行是列表头,第二行ppptszResult(col)才是数据
