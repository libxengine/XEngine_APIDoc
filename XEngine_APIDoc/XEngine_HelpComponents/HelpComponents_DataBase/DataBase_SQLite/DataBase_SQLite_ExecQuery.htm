函数

DataBase_SQLite_ExecQuery

功能

执行查询语句

语法

bool DataBase_SQLite_ExecQuery(XNETHANDLE xhData, LPCXSTR lpszQueryStr, XCHAR*** ppptszResult, __int64u* pInt_Row, __int64u* pInt_Column)

参数

 参数.一：xhData
  In/Out：In
  类型：数据库句柄
  可空：N
  意思：要对哪个数据库进行操作
 参数.二：lpszQueryStr
  In/Out：In
  类型：常量字符指针
  可空：N
  意思：要执行的SQL语句
 参数.三：ppptszResult
  In/Out：Out
  类型：三级指针
  可空：N
  意思：保存结果的记录集数据  ppptszResult[i]
 参数.四：pInt_Row
  In/Out：Out
  类型：整数型指针
  可空：N
  意思：执行后影响的行数
 参数.五：pInt_Column
  In/Out：Out
  类型：整数型指针
  可空：N
  意思：执行后影响的列数

返回值

类型：逻辑型
意思：是否成功

备注

返回的数据集第一行是列表头,第二行ppptszResult(col)才是数据
