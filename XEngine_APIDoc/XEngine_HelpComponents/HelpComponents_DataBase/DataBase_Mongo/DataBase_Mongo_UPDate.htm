函数

DataBase_Mongo_UPDate

功能

更新一条数据

语法

bool DataBase_Mongo_UPDate(XNETHANDLE xhNet, LPCXSTR lpszQueryStr, LPCXSTR lpszCollName, LPCXSTR lpszQueryUPdate, bool bBson = true)

参数

 参数.一：xhNet
  In/Out：In
  类型：句柄
  可空：N
  意思：输入数据库句柄
 参数.二：lpszQueryStr
  In/Out：In
  类型：常量字符指针
  可空：N
  意思：要操作的查询字符串
 参数.三：lpszCollName
  In/Out：In
  类型：常量字符指针
  可空：N
  意思：要操作的集合
 参数.四：lpszQueryUPdate
  In/Out：In
  类型：常量字符指针
  可空：N
  意思：更新到的结构
 参数.五：bBson
  In/Out：In
  类型：逻辑型
  可空：Y
  意思：操作的查询数据结构是Bson还是json

返回值

类型：逻辑型
意思：是否成功
