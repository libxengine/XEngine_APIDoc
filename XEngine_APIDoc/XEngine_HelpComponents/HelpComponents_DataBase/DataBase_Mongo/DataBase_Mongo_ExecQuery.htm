函数

DataBase_Mongo_ExecQuery

功能

通过BSON查找一条数据

语法

bool DataBase_Mongo_ExecQuery(XNETHANDLE xhNet, LPCXSTR lpszQueryStr, LPCXSTR lpszCollName, XCHAR*** ppptszList, int* pInt_ListCount, bool bBson = true, LPCXSTR lpszQueryOPT = NULL)

参数

 参数.一：xhNet
  In/Out：In
  类型：句柄
  可空：N
  意思：输入数据库句柄
 参数.二：lpszQueryStr
  In/Out：In
  类型：常量字符指针
  可空：N
  意思：查询语句
 参数.三：lpszCollName
  In/Out：In
  类型：常量字符指针
  可空：N
  意思：要操作的集合
 参数.四：ppptszList
  In/Out：Out
  类型：三级指针
  可空：N
  意思：导出获取到的数据JSON结构
 参数.五：pInt_ListCount
  In/Out：Out
  类型：整数型指针
  可空：N
  意思：获取到的列表个数
 参数.六：bBson
  In/Out：Out
  类型：逻辑型
  可空：Y
  意思：查询的数据结构是Bson还是json
 参数.七：lpszBsonOpt
  In/Out：Out
  类型：常量字符指针
  可空：Y
  意思：BSON查询选项,可以为NULL

返回值

类型：逻辑型
意思：是否成功

备注

参数ppptszList需要调用基础库的BaseLib_Memory_Free函数进行内存释放
