函数

DataBase_Mongo_Count

功能

文档统计

语法

bool DataBase_Mongo_Count(XNETHANDLE xhNet, LPCXSTR lpszQueryStr, LPCXSTR lpszCollName, int* pInt_Count, bool bBson = true)

参数

 参数.一：xhNet
  In/Out：In
  类型：句柄
  可空：N
  意思：输入数据库句柄
 参数.二：lpszQueryStr
  In/Out：In
  类型：常量字符指针
  可空：N
  意思：要操作的查询条件
 参数.三：lpszCollName
  In/Out：In
  类型：常量字符指针
  可空：N
  意思：要操作的集合
 参数.四：pInt_Count
  In/Out：In
  类型：整数型指针
  可空：N
  意思：获取到的统计个数
 参数.五：bBson
  In/Out：In
  类型：逻辑型
  可空：Y
  意思：输入查询条件是BSON还是JSON格式，默认BSON

返回值

类型：逻辑型
意思：是否成功
