函数

DataBase_Mongo_Execute

功能

执行一条命令并且获得回复

语法

bool DataBase_Mongo_Execute(XNETHANDLE xhNet, LPCXSTR lpszQueryStr, XCHAR* ptszMSGBuffer, int* pInt_MSGLen, bool bBson = true)

参数

 参数.一：xhNet
  In/Out：In
  类型：句柄
  可空：N
  意思：输入数据库句柄
 参数.二：lpszQueryStr
  In/Out：In
  类型：常量字符指针
  可空：N
  意思：要操作的结构
 参数.三：ptszMSGBuffer
  In/Out：Out
  类型：常量字符指针
  可空：N
  意思：导出服务器的返回内容格式。
 参数.四：pInt_MSGLen
  In/Out：In/Out
  类型：整数型指针
  可空：N
  意思：输入提供的缓冲区大小，输出获取到的缓冲区大小
 参数.五：bBson
  In/Out：In
  类型：逻辑型
  可空：Y
  意思：输入数据是BSON还是JSON格式，默认BSON

返回值

类型：逻辑型
意思：是否成功

备注

通用执行接口,支持插入删除等操作,但是需要自己组装
